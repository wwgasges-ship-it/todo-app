# 치즈를 지켜라! 방귀 대소동

사진을 참고해 만든 주인공과 장난꾸러기 괴물이 등장하는 치즈 수집 게임입니다.

실행 주소: https://wwgasges-ship-it.github.io/todo-app/games/neoguri/

## 게임 방법

사다리를 타고 치즈를 모두 모으세요. 괴물과 방귀 구름에 닿으면 목숨이 줄어듭니다. 점프로 피할 수 있습니다. 치즈 하나당 100점이며 5개 단계를 모두 깨면 성공합니다.

| 단계 | 장소 | 치즈 | 괴물 | 방귀 구름 | 시간 |
| --- | --- | --- | --- | --- | --- |
| 1 | 치즈 정원 | 20개 | 2마리 | 1개 | 180초 |
| 2 | 노을 치즈 마을 | 24개 | 3마리 | 2개 | 180초 |
| 3 | 방귀 버섯 숲 | 28개 | 4마리 | 3개 | 180초 |
| 4 | 치즈 요새 | 32개 | 5마리 | 4개 | 180초 |
| 5 | 방귀 대마왕의 성 | 36개 | 6마리 | 5개 | 180초 |

단계가 높아질수록 괴물은 빨라지고 사다리의 배치와 배경도 바뀝니다. 단계를 완료하면 **다음 단계**를 누릅니다. 누적 점수는 이어지고 목숨 3개와 180초가 새로 주어집니다.

게임 오버 때 **이 단계 다시 도전**을 누르면 해당 단계의 시작 점수부터 다시 시작합니다. **1단계부터**는 전체 진행을 초기화합니다.

- 스마트폰: 방향 버튼을 누른 채 이동합니다. 사다리 가까이에서 ▲/▼를 눌러 오르내립니다. 방향과 점프를 동시에 누를 수 있습니다.
- 컴퓨터: 방향키 또는 WASD로 이동하고 스페이스로 점프합니다. P로 일시정지/재개합니다.
- 점프는 한 번 누를 때 한 번 실행됩니다. 다시 점프하려면 뗐다가 누르세요.
- 다른 탭으로 이동하면 자동 일시정지됩니다. 계속하기를 누르면 재개됩니다.
- 목숨이 줄어도 그 단계에서 모은 치즈는 유지됩니다. 깜빡이는 동안은 잠깐 무적입니다.

최고 점수는 현재 브라우저에 저장되며 기존 최고 점수도 유지됩니다. 현재 단계 진행은 새로고침 시 초기화됩니다.

## 캐릭터

주인공과 괴물은 사용자가 제공한 두 사진의 특징을 참고해 만든 투명 배경의 게임용 이미지입니다. 원본 사진은 저장소에 포함하지 않습니다. 이미지 로딩에 실패하면 대체 픽셀 캐릭터가 표시됩니다.

## 개발 및 테스트

HTML, CSS, JavaScript만 사용하며 설치나 빌드가 필요 없습니다. 기존 할 일 앱과 같은 저장소의 games/neoguri 폴더에 있습니다.

- engine.js: 단계 구성, 이동, 사다리, 점프, 충돌, 점수와 게임 상태
- game.js: 그림, 입력 처리, 단계별 화면, 최고 점수 저장
- index.html / style.css: 한국어 화면과 반응형 조작 버튼
- assets/: 게임용 캐릭터 이미지
- tests/engine.cjs: 외부 의존성 없는 규칙 테스트

저장소 루트에서 `node games/neoguri/tests/engine.cjs`를 실행합니다.

규칙 테스트 17개와 가상 DOM·캔버스 기반 연동 테스트 16개, JavaScript 구문 검사를 통과했습니다. 5개 단계의 수집 경로는 적과 방귀를 제외한 지형에서 검증했으며 충돌/점프 회피는 별도 검사했습니다. 실제 브라우저 렌더링, 스마트폰 멀티터치와 기기 성능은 개발 환경에서 검증하지 못했습니다.
