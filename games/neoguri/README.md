# 너구리 과일 원정대

새 픽셀 캐릭터로 만든 1개 스테이지의 과일 수집 웹게임입니다.

실행 주소: https://wwgasges-ship-it.github.io/todo-app/games/neoguri/

## 게임 방법

100초 안에 과일 24개를 모으면 성공합니다. 과일 하나당 100점입니다. 목숨은 3개이며 슬라임이나 폭탄에 닿으면 하나 줄어듭니다. 피격 후 잠깐 깜빡이는 동안에는 무적입니다. 목숨이 줄어도 모은 과일은 유지됩니다.

- 스마트폰: 화면 아래 방향 버튼을 누른 채 이동합니다. 사다리 가까이에서 ▲/▼를 눌러 오르내립니다. 이동 버튼과 점프를 함께 누를 수 있습니다.
- 컴퓨터: 방향키 또는 WASD로 이동하고 스페이스로 점프합니다. P로 일시정지/재개합니다.
- 점프는 누를 때마다 한 번씩 실행됩니다. 다시 뛰려면 버튼을 뗐다가 누릅니다.
- 일시정지 버튼이나 다른 탭으로 이동하면 게임이 멈춥니다. 계속하기를 누르면 재개됩니다.
- 처음부터를 누르면 현재 진행이 초기화됩니다.

최고 점수만 해당 브라우저에 저장됩니다. 새로고침하면 현재 게임은 초기화됩니다.

## 파일 및 개발

빌드와 설치가 필요 없는 HTML, CSS, JavaScript입니다.

- index.html: 화면과 터치 버튼
- style.css: 반응형 디자인
- engine.js: 이동, 사다리, 중력, 충돌, 점수와 게임 상태
- game.js: 캔버스 그림, 입력 처리, 화면 갱신 및 최고 점수 저장
- tests/engine.cjs: Node.js만으로 실행하는 규칙 테스트

`node games/neoguri/tests/engine.cjs`로 규칙 테스트 13개를 실행할 수 있습니다.

## 검증 범위

규칙 테스트 13개와 가상 DOM/캔버스 기반 연동 테스트 11개가 통과했습니다. 두 JavaScript 파일의 구문 검사도 통과했습니다. 연동 테스트는 시작, 터치 입력/해제, 이동+점프 동시 입력, 터치 취소, 일시정지/재개, 탭 이탈, 키보드, 최고 점수, 재시작과 프레임 호출, 이미지 렌더링/좌우 반전, 이미지 실패 시 대체 표시를 확인했습니다.

실제 브라우저 렌더링, 실제 스마트폰 멀티터치, 기기 성능은 개발 환경에서 확인하지 못했습니다. 첫 실행에서 시작 버튼, 방향 버튼, 점프와 사다리 이동을 확인해 주세요.

## 사진 캐릭터

사진의 앞머리, 양갈래 머리와 흰 원피스를 참고해 만든 캐릭터를 사용합니다. assets/photo-hero-v1.webp는 투명 배경의 게임용 이미지입니다. 원본 사진은 저장소에 포함하지 않습니다. 캐릭터는 방향을 바꾸고 걸을 때 살짝 흔들리며, 이미지 로딩에 실패하면 대체 픽셀 캐릭터로 표시됩니다.
